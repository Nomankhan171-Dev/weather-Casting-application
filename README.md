# Atmos Weather App

A modern weather app built with **React JS + CSS + REST API integration**.

## Features
- Search weather by city
- Current weather
- Feels-like temperature
- Humidity
- Wind speed
- Rain information
- 6-day forecast
- Sunrise and sunset
- Browser geolocation
- Responsive UI

## API
This project uses the free Open-Meteo APIs:
- Geocoding API
- Forecast API

No API key is required.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Main technologies
- React JS
- CSS
- REST API
- Vite
